# 5-апта: индекс буфері (EBO)

Үшбұрыштың орнына төртбұрыш: 4 вершина + 6 индекс, `glDrawElements` арқылы сызылады.
4-аптадағы анимация (орбита, пульсация, басқару) өзгеріссіз қалды.

## Құрастыру (MinGW)

```
g++ -std=c++17 main.cpp glad/src/gl.c -Iglad/include -Iinclude -Llib-mingw-w64 -lglfw3 -lgdi32 -o main.exe
```

## Басқару

| Перне | Әрекет |
|---|---|
| Space | төртбұрыш ↔ бесбұрыш |
| W / S | айналу жылдамдығы + / − |
| Q / E | орбита радиусы − / + |
| R | бастапқы күйге қайтару |
| Esc | шығу |

## Не өзгерді

- `vertices` — 4 вершина (0.3f, орбитамен бірге NDC-ден шықпайды)
- `indices` — `{0, 1, 3,  1, 2, 3}`, 1 мен 3 екі рет қолданылады
- EBO **VAO байланып тұрғанда** жасалады (`createMesh` функциясы), `GL_ELEMENT_ARRAY_BUFFER` босатылмайды
- `glDrawArrays(GL_TRIANGLES, 0, 3)` → `glDrawElements(GL_TRIANGLES, 6, GL_UNSIGNED_INT, 0)`
- Тазалауда `glDeleteBuffers(1, &ebo)` қосылды

## 1-тапсырма: индекстер `{0, 1, 2}`

Тек **бір үшбұрыш** көрінеді — 0 (оң жоғарғы), 1 (оң төменгі), 2 (сол төменгі) вершиналары,
яғни төртбұрыштың оң-төменгі жартысы. 3-вершинаға (сол жоғарғы) ешбір индекс сілтемейді,
сондықтан ол вершина VBO-да жатса да, сызылмайды.

Сонымен қатар `glDrawElements`-тің екінші параметрін 6-дан **3-ке** түсіру керек. Әйтпесе
GPU 12 байттық EBO-дан 6 индекс (24 байт) оқуға тырысады — буфер шегінен шығу, нәтижесі
анықталмаған (драйверге байланысты: ештеңе шықпайды, қоқыс геометрия немесе құлау).

## 2-тапсырма: бесбұрыш

5 вершина шеңбер бойында (радиус 0.3, 90°-тан бастап 72° сайын, сағат тіліне қарсы).
0-вершинадан желпуіш (fan) тәсілімен 3 үшбұрышқа бөлінеді:

```
          0
        / | \
      1   |   4        үшбұрыштар: (0,1,2)  (0,2,3)  (0,3,4)
       \  |  /         диагональдар: 0–2 және 0–3
        2---3
```

```cpp
unsigned int pentaIndices[] = { 0, 1, 2,   0, 2, 3,   0, 3, 4 };
glDrawElements(GL_TRIANGLES, 9, GL_UNSIGNED_INT, 0);
```

`glDrawArrays`-пен бұл 9 вершина болар еді, EBO-мен — 5 вершина + 9 индекс.
Space арқылы көрсетіледі.

## 3-тапсырма: екі рет салу

Бір `glBindVertexArray`, одан кейін екі рет `glUniform*` + `glDrawElements`:
бірінші фигура сағат тіліне қарсы 0.4 радиуспен, екіншісі сағат тілімен 0.2 радиуспен
қозғалады. VAO бір рет байланады — EBO оның ішінде, қайта байлау керек емес.

## Ескерту: айналу бағыты

Тапсырмадағы `{0, 1, 3,  1, 2, 3}` индекстері шын мәнінде **сағат тілімен** жүреді
(0 оң жоғарғы → 1 оң төменгі → 3 сол жоғарғы). Қазір бұл көрінбейді, бірақ 8-аптада
`GL_CULL_FACE` қосқанда төртбұрыш жоғалады. Сағат тіліне қарсы нұсқасы:
`{0, 3, 1,  1, 3, 2}`. Бесбұрыштың индекстері сағат тіліне қарсы.
